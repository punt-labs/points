# Claude compatibility

OpenCode is the primary development harness for this repository. The canonical
project instructions are in [`AGENTS.md`](AGENTS.md).

Claude-compatible tools must read and follow `AGENTS.md`; this file intentionally
does not duplicate project policy. Tool-specific setup remains in
`docs/SETUP.md`, and the Beads/Ethos development loop remains in
`docs/WORKFLOW.md`.
